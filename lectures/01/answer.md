# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：基礎・実装・発展の3段階があり、どれか1つに取り組めば宿題を完了できる。
- 用語集の正しい意味と比べて気づいたこと：モデルの回答は用語集の定義とおおむね一致していた。会話履歴がない状態では、講座固有の内容を正確に答えられない場合がある。
- 表示できたトークン数（入力 / 出力）：実行ごとに異なるため、`[入力トークン数]` と `[出力トークン数]` として実行時に表示される。
例：
input : uv run python -m app.ask "LoRAとは何ですか？"
output:  [入力トークン数] 596、[出力トークン数] 666

## 宿題

- 取り組んだレベル：実装
- やったこと：`client.chats.create()` でチャットを作成し、同じチャットに対して `send_message()` で続けて質問するよう `app/ask.py` を改修した。
- 結果：最初の質問への回答後も入力待ちになり、`exit` または `quit` を入力するまで会話履歴を保ったまま続けて質問できるようになった。
- 気づき・疑問：会話履歴が蓄積されるため、後の質問では入力トークン数が増える。長い会話ではコンテキストウィンドウやトークン使用量への影響を確認する必要がある。
